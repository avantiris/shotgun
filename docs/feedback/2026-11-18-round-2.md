# Feedback round 2, 2026-11-18 (first look at stage 1)

### F2.1 Adding tracks is not intuitive
- Said: "it is not intuitive enough to add new tracks for video and audio"
- Kind: workflow
- Area: timeline
- Status: fixed (see commit of this file)
- Was: two buttons at the bottom of the inspector, visible only with no clip
  selected.
- Now: `+ Video` and `+ Audio` sit above the track names in the timeline; a
  right click on the timeline offers the same and removes an empty track;
  and a drop makes the tracks it needs, so adding one by hand is rarely
  necessary. The inspector buttons stay.

### F2.2 Dragging a video onto a track does not work
- Said: "drag n drop of videos to the track does not work"
- Kind: missing
- Area: timeline
- Status: fixed (see commit of this file)
- Read as both gestures, since neither existed: dragging an asset tile from
  the panel onto the timeline, and dropping files from another application
  onto the timeline (which only imported them).
- Now: both place the media where it is let go (07-ui-keybinds.md, Mouse).
- Verified: the tile drag by a test that feeds press, move and release
  through egui's input handling (`dragging_an_asset_tile_onto_the_timeline_places_it`);
  placement rules by unit tests; the result by a scripted run with a
  screenshot. Not verified: the gesture with a real mouse, and a real drop
  from a file manager (its position reaches the same code, untested).
